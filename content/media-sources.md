# Catalog media sources

The M2 deterministic seed reuses ten legacy product cutouts from the original
training storefront in
`public/img/sneakers/*.png` only as catalog-card placeholders.

- Origin: assets already present in the legacy training repository before the
  Solecraft transformation. This note intentionally preserves source attribution.
- Current dimensions: 266×224 px.
- Allowed milestone use: local/test portfolio development and compact catalog cards.
- Not claimed: original photography ownership, retailer attribution, PDP quality, or
  production merchandising rights.
- Public release gate: replace or explicitly license/generate production-quality PDP
  sources before public merchandising; the current deterministic gallery remains a
  local/test portfolio placeholder.

The database stores explicit width/height and descriptive alt text for every seeded media
row. No remote retailer image URL or MockAPI media endpoint is used.
